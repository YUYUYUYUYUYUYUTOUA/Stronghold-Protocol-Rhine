# 独立战斗测试模式

分支：`codex/test-lab`；测试包：`v0.1.3-lab.2`。基于上游 v0.1.3 与莱茵扩展 v0.1.3-rhine.2，包含科研成果共享、能量 AOE、生态减速、研究主机无攻击上限，以及梅尔有效工作产层、溯光星源莱茵加层、装置每层 4 攻击和伊芙利特最高单台 100% / 150% 继承。

## 启动

完整解压 Windows 测试整合包，双击根目录 **启动测试模式.bat**。它优先使用包内 Node，在 **127.0.0.1:3010** 启动本地服务并打开 **/dev/test-lab.html**。保留启动窗口；按 Ctrl+C 停止这次测试服务。再次双击会复用已运行的测试入口。

端口被其他程序占用时，可在本包目录运行 `启动测试模式.bat --port 3011`。测试启动器拒绝使用正式 3000 端口。它不修改防火墙、隧道、正式游戏目录或正式对局。

源码运行：先按主 README 完成依赖、数据和素材准备，再运行 `npm run test-lab`。浏览器需支持 WebGL；推荐当前 Chrome 或 Edge。

## 一次测试流程

1. 选择莱茵扩展或原版数据，再选地图、随机种子、回合。基础预设提供六名干员及一个生命 1000 万、攻击和移速为 0 的木桩；另有莱茵能量和生态预设。
2. 选择场上 UID，或点击地图上的单位。编辑普通/精锐、技能、适用模组、装备、格子和朝向，点击“应用所选单位”；也可以添加/删除干员、召唤物和敌人。普通干员沿用游戏的模组限制，精锐可更换模组。
3. 选择要测试的盟约，填写层数。人数默认按真实阵容自动计算，也可手动覆盖，隔离测试 3/6/9 人等门槛。应用后即采用真实规则计算属性。莱茵装置可分别设置一级、二级、三级；实际生效数量仍遵循人数对应的装置容量。
4. “允许战斗叠层”默认开启。对比相同层数的输出时关闭，战斗仍会正常施放技能、治疗和造成伤害，但不会继续产层；原有层数仍提供属性加成。点击“开始”观察真实战斗；支持 0.25、0.5、1、2、4 倍速、暂停和单步。单步推进 1/30 秒。重置回到当前配置开战状态，固定种子便于对照。
5. 在说明区检查所选技能、特性、天赋、协议特质、模组、盟约说明；实时数值区显示生命、技力、攻击、防御、法抗、攻速间隔、伤害和 DPS 等实际状态。
6. 导出 JSON 或保存到本机，保存一套阵容；换层数或阵容后重新跑，比较输出。导入可在原版/莱茵之间切换。本机保存位于此浏览器的 localStorage，换浏览器或端口不会自动共享；下载 JSON 可跨设备保存。

## 动作与特效

“强制释放”调用所选干员当前技能的真实引擎，免除技力费用，保留技能的其他限制。被动技能、已持续开启的技能或未部署单位不能重复强制开启。技能持续时间、后续攻击与伤害需要继续播放或单步。

动作列表读取当前模型真正包含的 Spine 动画，可播放 Attack、Idle、Start 等动作并选择循环；具体名称随模型变化。素材未加载、素材没有相应动作或装置使用程序动画时，界面会提示暂无可用动作。动作预览会暂停战斗，只改变模型表现。

特效下拉列表调用项目现有渲染器，以所选单位和最近敌人为预览位置。特效预览只观看，不造成伤害；技能引擎触发的特效伴随真实战斗。播放动作后点“开始”恢复战斗驱动的正常动作。

## 测试边界

- 测试场景使用真实 `BattleSpec`、战斗引擎、盟约计数、技能/模组解析和渲染素材，在当前浏览器运行；不建立联机房或在线对局。
- 这里测试单场战斗，不走商店、BAN、悬赏、领袖选择、跨回合成长和对局结算流程。层数为开战时的指定值，是否继续产层由开关决定；研究阶段由工具指定。溯光星源的资金结算须在正式回合流程测试，这里可手动设置相应层数。
- 格子使用普通战场绝对坐标：行 9–12、列 0–10。测试允许忽略职业地形和人口限制，但友方不能占同一格。地图障碍、环境装置与敌人路线仍按真实引擎处理；某些格子可能被环境阻挡，应在另一空格重试。
- 盟约层数范围 0–999，手动人数 0–20，友方最多 44 个，每个敌人组最多 30 个、总计最多 600 个。敌人数值有校验范围，0 移速用于木桩。多个同种敌人组可以使用不同属性；选择一组查看其中首个存活单位。
- 开战初始化会部署和推进第一帧（显示 0.03 秒），随后暂停。部署入场特效会自行收尾。暂停控制真实战斗时钟；单独动作/特效预览按视觉时钟播放。
- 所有玩家干员在原战斗引擎中属于友方。本测试台比较不同盟约的阵容效果，不提供阵营互相攻击的 PvP 模式。

## 开发验证

纯模型和控制器：`node --test test/testLabScenario.test.js test/testLabController.test.js test/ui/test_lab_ui.test.js`。

浏览器验证（需要系统 Chrome 与 puppeteer-core）：PowerShell 设置 `$env:SP_E2E='1'` 和 `$env:CHROME_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'`，运行 `node --test test/e2e/test-lab.e2e.mjs`。测试在临时端口启动独立服务，完成即关闭；涵盖地图与真实模型、层数/人数、装备/技能/模组、强制施放、暂停/单步、动作/特效、敌人编辑、JSON、数据档隔离和窗口布局。
