# 莱茵扩展变更记录

## 2026-10-04 · 科研规则与战斗显示 v0.1.1-rhine.2

- 梅尔机械水獭的库存和同时部署上限改为普通 1 只、精锐 2 只，涵盖所有技能与模组配置。
- 机械水獭禁止干员治疗，包括塞雷娅及干员的医疗召唤物；生命维持仪仍可治疗水獭。
- 白面鸮保留休整期结束触发，每名实际在场莱茵干员提供 2 层，精锐 4 层；同名干员逐个计数，调和虚拟人数和召唤物不计，多名白面鸮仍只取最强者触发一次。
- 莱茵生命增加 9 人档位：3 / 6 / 9 人分别允许 1 / 2 / 3 种装置上场，掉档时收回超出容量的装置。
- 装置预放置、选中和生态区域改为整格显示，实际充能、治疗与选敌采用相同格子判定。基础范围为 13 格，成熟生态为 29 格；地图边缘裁剪，不受朝向影响。
- 能量谐振仪增加塔下充能条，实时及重连同步；增加发射闪光、指向目标的光束和命中反馈，低画质也可辨认。
- 本次不新增干员；原有研究点突破、装备及技能模组选择继续保留。游戏基础版本仍显示 0.1.1。

验证：全量回归 3515 项，3506 通过、0 失败、9 项因原始缓存或可选环境跳过；另有真实 Chromium 画面回归 3 项全部通过，覆盖选中／预放置、领袖阵地镜像、网络充能快照和低画质攻击反馈。整合包解压、资源和联机另行验收。这些检查不等同于完整人工多人对局或平衡性验证。

## 2026-10-04 · Windows 便携整合包 v0.1.1-rhine.1

- 提供包含莱茵 0.1.1 源代码、游戏素材、依赖和官方 Node.js 24 的 Windows x64 完整安装包；解压后双击根目录 `启动莱茵科研版.bat` 即可启动，无需安装开发工具。
- 启动器优先使用内置运行环境，检查已占用端口是否属于同目录、同数据的莱茵服务，避免打开旧版或其他服务；不会停止已有服务。
- 增加可复用打包工具、文件 SHA256 清单及整合包使用说明；原项目署名、代码和第三方组件许可随包保留。
- 本次不修改游戏规则或数值；旧版本请保留在独立目录，结束对局后再切换服务。
