# 莱茵生命扩展整合包使用说明

当前版本为 **`v0.3.0-rhine.12` 测试候选**，兼容版本 `0.3.0`，修改日期 2026-10-22，正式开发分支 `codex/rhine-upstream-021`。本轮已获测试版发布授权；实际发布、附件与流水线状态以发行页及[本轮验证记录](RHINE-20261022-VALIDATION.md)为准。

发布完成后，从 [`.12` 测试版发行页](https://github.com/YUYUYUYUYUYUYUTOUA/Stronghold-Protocol-Rhine/releases/tag/v0.3.0-rhine.12) 下载完整 **`Stronghold-Protocol-Rhine-v0.3.0-rhine.12-Windows-x64.zip`**。这是适用于 Windows 64 位电脑的完整便携包，包含莱茵、卡兹戴尔、雷姆扩展、运行依赖、素材和官方 Node.js 24 运行时，无需另外安装 Node.js。

本版适配上游 v0.3.0，固定提交 `c24e17eec3af1e6dedfa9935a6d15245cf2f4586`，不引入该标签之后的 master。扩展干员支持相同的潜能／练度设置；原版与扩展分别保存调配偏好。

本次测试候选纳入已确认的维什戴尔普通／精锐炮伤50%／80%基础加攻及魂灵继承、雷姆3／6／9档成长与Boss锁定／老板定点轰炸、左右协防援军寻路、逻各斯活体专属，以及矿业护具和工头的扩音器两件雷姆专属装备。人物策略完全排除。精确机制见 [卡兹戴尔说明](KAZDEL.md)、[雷姆必拓](REM.md)和[科研装置说明](RHINE.md#科研装置)；测试通过范围与未验证事项见[本轮验证记录](RHINE-20261022-VALIDATION.md)。

`.12` 按 GitHub 测试版发布（`prerelease: true`、`makeLatest: false`），本轮不替换正式 latest，正式最新版仍为 `v0.3.0-rhine.11`。默认联网更新只选择正式最新版，不会自动选中 `.12` 测试版。

## 解压并开始

1. 将整个 ZIP 解压到一个新文件夹，例如 `D:\Games\Stronghold-Rhine`。不要直接在压缩包里运行。
2. 双击包根目录的 **`启动莱茵科研版.bat`**。启动窗口需要保持打开。
3. 浏览器会打开游戏；若未自动打开，访问 **<http://127.0.0.1:3000/>**。
4. 选择“独立模拟”开始单人游戏，或选择“同盟模拟”创建房间，与朋友一起玩。
5. 新房间的“莱茵／卡兹戴尔扩展”默认开启。房主可在等待室选择“原版”，使用随包固定的上游 v0.3.0 原版数据；只有开局前可切换，各房间独立设置。切换后队友需重新准备，数据与本局调配完成后才允许开局。

这是**完整便携包**。测试 `.12` 建议解压到新目录：先让玩家结束对局并关闭旧服务，仅按[保配置更新说明](RHINE-UPDATE.md)迁移自己的私有配置和插件，不将旧游戏代码或 `data` 覆盖进新目录。默认 **联网更新.bat**／**更新旧版.bat** 仍获取正式 latest，不会自动安装测试版。不要直接解压覆盖已有安装；若旧服务占用3000端口，先关闭它再启动新目录服务，仅打开相同网址不会切换运行版本。服务内存中的房间和对局不能通过重启或换版继续。

## 和朋友一起玩

支持 1–6 人同房合作，真人与 AI 共用六个席位。只有房主需要下载并启动整合包，其他玩家使用浏览器加入即可；规则见 [多人版说明](MULTIPLAYER.md)。

五至六人悬赏决策提供九张牌，新增三张现有 I / II / II 阶目标，赏金分别为 1 / 2 / 2；单人与一至四人的悬赏张数不变。六人局开场核心 BAN 相比一至四人少两个（五人少一个），共享 BOSS 血量为同规则四人局的 200%；第 10、12、14 回合每位存活玩家各获一个信标，第 14 回合奖励信标即时转赠。莱茵扩展开启时，多萝西普通与精锐调整为 IV 阶。对局开始后扩展开关锁定，断线重连保留本局选择，原版与莱茵版分别保存干员调配偏好。

- **同一局域网**：把启动窗口显示的局域网网址发给朋友，例如 `http://192.168.0.101:3000/`，再分享房间的同盟密钥或房间链接。朋友不能使用你的 `127.0.0.1` 地址。
- **异地联机**：房主先使用自己的内网穿透服务或虚拟局域网，再分享该入口下的游戏网址和同盟密钥。整合包不包含预设公网隧道、账号或令牌；具体配置见 [部署说明](DEPLOY.md)。
- Windows 首次提示网络访问时，局域网联机需要允许 Node.js 在所用的专用网络上通信。

## 对局保留与关闭

房间和对局保存在服务器内存中。**关闭启动窗口、结束服务、重启电脑或切换版本，都会结束当前全部对局；本包不提供重启后继续上一局的磁盘存档。**

只关闭浏览器不等于放弃对局：服务仍运行时，同一浏览器、同一访问地址可尝试断线重连；独立模拟通常保留 24 小时，同盟模拟通常保留 10 分钟。正式结束自己的对局请在游戏左上角选择“离开”→“放弃模拟”。停服前请让所有玩家结束对局。
