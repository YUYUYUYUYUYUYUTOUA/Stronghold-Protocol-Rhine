# 保留配置的原地更新

`v0.1.3-rhine.4` 起，完整包根目录提供 **更新旧版.bat**。旧版不会自动出现这个入口，要从新包运行它。此前的莱茵便携包只要根目录有 `bundle-manifest.json`，也可以作为更新目标。

## 普通玩家怎么更新

1. 下载最新 Windows x64 完整整合包，**解压到一个临时的新目录**。不要直接解压覆盖旧目录。
2. 等旧服务的所有对局结束，关闭旧启动窗口。使用开机自启的用户先停止对应服务，防止它在更新时自动启动。工具不停止进程、不重启服务。
3. 在新包根目录双击 **更新旧版.bat**，输入原来游戏所在的旧目录，例如 `D:\Games\Stronghold-Rhine`。选到的目录内应直接有 `bundle-manifest.json`。
4. 工具核对新包全部文件和新旧差异，通过后在旧目录的 `.rhine-updates\时间-编号\` 备份本次要替换或删除的文件，然后原地更新。
5. 看到“更新完成”后，**回到原来的旧目录**启动游戏。继续使用原协议、地址和端口，让浏览器沿用原来的昵称、设置和调配偏好。

使用 Windows 本地目录，新旧目录不能相同或相互嵌套。更新目标须是带清单的莱茵便携包；上游官方整合包、源码 ZIP 和自行拼装的目录不一定有这份清单，工具会拒绝猜测，需另行迁移。

## 哪些内容会保留

| 内容 | 处理 |
| --- | --- |
| `scripts/service.env.cmd`，`.env` / `.env.*`，`.npmrc` 等本机文件 | 不覆盖、不读取内容、不上传 |
| `logs/`、`*.log`、`.cache/`，其它清单外本地文件 | 保留，不清空旧目录 |
| 用户修改的脚本、游戏规则或资源 | 新版官方内容未变化时保留；新版也改了同一个文件时报告冲突并停止 |
| 昵称、音量、画质、技能和模组选择 | 保存在浏览器同源存储中，文件更新不会清除 |
| 房间、进行中的对局 | 保存在服务器内存中，停服后无法恢复；先结束对局再更新 |

浏览器“同源”指**协议、主机和端口都相同**。`localhost:3000` 与 `127.0.0.1:3000` 是两份设置，换 IP、端口或公网域名也会显示另一份，不能据此判断设置被删。

`data/config.json` 和其它规则数据要随版本更新，不是用户设置。`data/local-assets.json` 与本地提取贴图属于资源：未修改的随版本升级；用户修改过且新版也有变化时报告冲突，避免新程序配旧索引。保留 `.env` 不表示当前启动器会自动加载它。

更新只处理新旧清单管理的文件。旧版清单中的文件如新版已删除，且本机内容仍与旧版相同，工具会先备份再移除；不会删除其它文件。新增文件若与用户自加文件撞名且内容不同，也会停止。工具不会修改开机任务、防火墙、隧道或认证策略。

## 冲突、失败和回退

有冲突时没有安装任何新文件，窗口会列出路径，不输出文件内容。请在保留备份的前提下比较自定义改动与新版内容，合并后再更新；不要简单把整个 `data/` 或 `scripts/` 跳过。

复制出错时工具尝试恢复已替换文件。若更新期间断电或窗口被关闭，可能留下部分文件新、部分旧的状态；保留新包和 `.rhine-updates` 中的备份，用下面的回退命令恢复，不要直接启动混合版本。

在 PowerShell 中可只读预检：

```powershell
& 'D:\Downloads\新包\更新旧版.bat' --target 'D:\Games\Stronghold-Rhine' --check
```

在服务已关闭的情况下回退，备份目录替换为更新窗口显示的实际路径：

```powershell
& 'D:\Downloads\新包\更新旧版.bat' --target 'D:\Games\Stronghold-Rhine' --rollback 'D:\Games\Stronghold-Rhine\.rhine-updates\时间-编号'
```

回退也会核对哈希。如更新后用户又修改了待恢复文件，或备份受损，工具拒绝覆盖这些内容。回退恢复程序文件，不能恢复已经结束的内存对局。确认新版稳定后再自行整理旧备份。

## 独立更新工具

Releases 另提供小体积 **Rhine-Update-Tool-Windows.zip**。完整解压工具包后双击其中的 **更新旧版.bat**，依次输入已解压的新完整包和旧安装目录。它使用新完整包内的 Node.js，不额外安装依赖；适合已经下载前一版完整包的用户。

工具源码随包提供于 `scripts/rhine-bundle-update.mjs` 和 `scripts/rhine-bundle-update.ps1`，不包含任何玩家配置或账号。
