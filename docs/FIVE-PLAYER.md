# 五人同盟模拟

本扩展从 `v0.1.2-rhine.2` 起支持 **1–5 人同房合作**。五个席位可由真人或 AI 队友组成；独立模拟仍只有一个席位。

只有房主需要启动服务，其他四人用浏览器打开房主的游戏网址，再用房间链接或同盟密钥加入。房间已满时，第六人会收到人数已满的提示。所有真人队友准备就绪后，房主即可开始。

## 对局规则

- 普通作战：每名玩家有自己的阵地，五人的作战进度和结果分别结算。
- 联防：沿用原有完美作战队友支援规则，一次最多两位支援者。第五人可以正常支援或被支援。
- 最终攻势与隐秘核心：按存活玩家的席位顺序两两组队。五人全部存活时为 **2＋2＋1** 三个阵地，最后一人单独迎战；有玩家淘汰时按剩余人数重新配对。沿用共享领袖生命池和原有奇数人数处理。
- 同一对局仍共用有限干员池；没有为第五人增加同名库存，其他房间的卡池保持独立。
- 领袖生命、伤害、商店抽取规则、莱茵科研和装备数值均保持现有版本设置。第五人会增加队伍总战力，也会使共享卡池的竞争更明显；本次属于人数扩展，尚未做五人专用平衡。

## 安装与切换

下载本 fork 的五人版完整整合包，解压到新目录，双击 `启动莱茵科研版.bat`。已运行的旧服务不会因为下载新版而自动切换；先结束旧对局并关闭旧服务，再启动新版。服务器重启会清除内存中的旧对局。

五名玩家都应刷新页面使用同一服务器提供的新版。大厅的同盟模拟说明应显示“1–5 名博士”，等待室应有 P1 至 P5 五个席位。

验证范围和结果见 [扩展变更记录](RHINE-CHANGES.md)。浏览器回归可使用 `CHROME_PATH` 指向已安装的 Chrome / Edge，并设置 `SP_E2E=1` 后运行 `node --test test/ui/five-player.e2e.test.js`；普通回归为 `node --test`。
