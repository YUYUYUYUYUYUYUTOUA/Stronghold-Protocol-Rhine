# 六人同盟模拟

当前扩展版本为 `v0.1.2-rhine.4`（2026-10-05，分支 `codex/rhine-toggle-update`），支持 **1–6 人同房合作**。真人与 AI 队友共用六个席位；独立模拟仍只有一个席位。

只有房主需要启动服务，其他五人用浏览器打开房主的游戏网址，再用房间链接或同盟密钥加入。房间已满时，第七人会收到人数已满的提示。所有真人队友准备就绪后，房主即可开始。

## 开局前选择莱茵扩展

新房间的“莱茵生命扩展”默认**开启**。房主可在等待室选择“开启”或“原版”，其他玩家能看到当前选择。独立模拟与同盟模拟均支持，每个房间独立设置。

选择“原版”后，本局切换到随包固定的上游 v0.1.2 原版游戏数据，恢复原版干员、阶数、盟约、特质、装备和机变内容；扩展干员、科研装置及莱茵装备不参与本局。已有的六个房间席位与多人规则仍然适用。

只能在开局前切换。切换后队友需要重新准备，浏览器等待对应数据完整加载并同步本局干员调配后，才允许准备或开始。开始后的对局固定使用开局时的选择，断线重连会继续该选择。两种数据的调配偏好分别保存，切回后恢复对应配置。

## 开场盟约轮换

开局时按实际参战的真人与 AI 合计人数决定 BAN 数量。五至六人的核心盟约少禁用一个，附加盟约不变；一至四人的规则保留。

| 模拟难度 | 1–4 人：核心 / 附加 BAN | 5–6 人：核心 / 附加 BAN |
| --- | --- | --- |
| 标准模拟 | 1 / 1 | **0 / 1** |
| 险境模拟 | 4 / 4 | **3 / 4** |
| 绝境模拟 | 4 / 4 | **3 / 4** |
| 终极模拟 | 4 / 4 | **3 / 4** |

这里只调整开场随机抽取的核心盟约，原有难度固定禁用盟约仍按原规则处理。开始后的离开、断线或淘汰不会重新抽取或改变这局 BAN；不同房间独立计算，训练模式保持不变。

## 对局规则

- 普通作战：每名玩家有自己的阵地，所有玩家的作战进度和结果分别结算。
- 联防：沿用原有完美作战队友支援规则，一次最多两位支援者；第五、第六人均可支援或被支援。
- 最终攻势与隐秘核心：按存活玩家席位顺序两两组队。五人全员存活时为 **2＋2＋1**；六人为 **2＋2＋2** 三个阵地。淘汰后按剩余人数重新配对，沿用共享领袖生命池和奇数人数独立阵地规则。
- 同一对局仍共用有限干员池，没有扩大每名干员的库存；其他房间的卡池保持独立。
- 五至六人开局时，悬赏决策保留原六张牌并追加三张现有目标，共 **9 张**；追加牌为 **I / II / II 阶**，赏金分别为 **1 / 2 / 2**。卡牌使用现有目标及其原有效果，队友仍按顺序每人选择一张；单人与一至四人沿用原悬赏张数。开局人数含 AI，后续断线或淘汰不会重算本局人数条件。
- 领袖生命、伤害、商店抽取规则、莱茵科研和装备数值保持现有设置。人数增加会提高队伍总战力，也会增加共享卡池的竞争；本次未做六人专用数值平衡。

莱茵扩展开启时，多萝西普通与精锐均为 **IV 阶**；技能、模组及陷阱规则见 [莱茵扩展说明](RHINE.md)。

## 安装与切换

下载本 fork 的六人版完整整合包，解压到新目录，双击 `启动莱茵科研版.bat`。旧服务不会因下载而自动切换；结束旧对局并关闭旧服务后，再启动新版。服务重启会清除内存中的旧对局。

所有玩家都应刷新页面使用同一服务器提供的新版。大厅应显示“1–6 名博士”，等待室应有 P1 至 P6 六个席位及“莱茵生命扩展”设置，开场确认页显示本局实际的 BAN 数量。

验证范围和结果见 [扩展变更记录](RHINE-CHANGES.md)。真实浏览器回归可使用 `CHROME_PATH` 指向已安装的 Chrome / Edge，设置 `SP_E2E=1` 后运行 `node --test test/ui/multiplayer.e2e.test.js`；普通回归为 `node --test`。
