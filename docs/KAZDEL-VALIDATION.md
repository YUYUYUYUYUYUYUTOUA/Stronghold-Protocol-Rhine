- 确认原炮击遍历共享战场所有友军，未过滤 ownerId。普通合作各玩家主战通常独立；联防及最终攻势／隐藏核心的共享战场存在跨玩家误伤路径。
- 六人档直接炮击对自己的活体友军为 `400 + 7.5 × S`，对敌仍为 `800 + 15 × S`。所有权由炮源、DamageInfo、生命流失的 from、死亡记录及同步／延迟回调传递，反伤者和战场权威客户端不能替代炮击原玩家。缺归属的炮击对友军保守免疫。

- 阿斯卡纶仅本体提供 20%／30% 范围额外减速，与原生减速相乘；每位玩家累计有效目标时间，每 3 秒 +1／2 层，同名取最强有效本体，多个目标不倍增，空档暂停保留余量，魂灵不参与。新增同名减速全场取最强，产层时钟按玩家独立。
- 原生三技能与模组直接复用已有 `op-ascln.js`；固定游戏表提交为 `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`。默认二技能“恩赐”，精锐默认 AMB-X 一级模组；普通、精锐面板／触发规则／模组与已有原生形态逐项一致。
- 数据语义差异仅为两个阿斯卡纶形态、两个特质，以及卡兹戴尔 bond/effect。已有干员、特质、config、tokens 均未改变；原版 data/vanilla 与黄金结果文件未改变。

## 全量初跑失败与复测

`npm run ci -- --keep-going` 的全量初跑为 **6313 测试：6238 通过、12 失败、63 跳过**。setup、smoke、lint、imports、typecheck 均通过，test 步骤失败。不能将这次命令称为全绿。

其中 11 个失败是新增成员后固定的成员／技能／卡池／素材数量断言，以及新增源码尚未进入 Git 跟踪导致的打包检查；这些已全部修正并通过上述受影响文件复测。未为修复计数断言重新运行耗时的整个全量套件。初跑的 9 类 solo/co-op 整场比赛各 20 个种子均到达 RESULT 且没有战斗错误。

**仍失败：`test/sim/fuzz.test.js` 的随机战斗 96。** 玛恩纳 `chess_char_5_19_a` 与“余音” `enemy_9023_acdums` 的反伤链超过 32 层，产生 `hookDepth:hit` / `hookDepth:damaged`。新增成员改变随机抽样后暴露该组合；已在完全未修改的 `509a666c` 独立 checkout 上，用只有玛恩纳和余音的最小场景复现相同错误，不需要炮击或阿斯卡纶。相关原版机制未混入本轮修改；该既有问题仍阻止当前随机测试／完整 CI 全绿。

复现脚本和原始记录位于本次云端交付目录 `/workspace/kazdel-validation/`，其中 `repro-echo.mjs` 可传入任意 checkout 路径。基线复现目录为 `/tmp/kazdel-baseline`。
