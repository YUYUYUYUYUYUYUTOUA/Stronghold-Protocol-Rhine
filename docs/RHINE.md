# 莱茵生命 · 联合科研（非官方扩展）

当前测试包：`v0.1.3-lab.2`；源码分支：`codex/test-lab`，基于稳定扩展 `v0.1.3-rhine.2`。

本扩展基于 [sganggs/Stronghold-Protocol](https://github.com/sganggs/Stronghold-Protocol) v0.1.3（官方发布提交 `a0a5419`），保留原玩法及该版本修复，并加入莱茵生命研究路线。修改日期为 2026-10-06。它是独立同人扩展，不是上游官方更新；修改范围见 [RHINE-CHANGES.md](RHINE-CHANGES.md)。

## 房间扩展开关

独立模拟与同盟模拟的新房间默认开启“莱茵生命扩展”。房主可在等待室选择“开启”或“原版”，所有玩家都能看到设置；只能在开始模拟前更改。切换会取消队友准备状态，并在对应数据加载、干员调配同步完成后恢复开局操作。各房间独立设置，对局开始及断线重连后继续使用本局固定选择。

“原版”使用随包固定的上游 v0.1.3 原版数据，恢复原版的干员、阶数、盟约、特质、装备和机变内容，扩展干员与科研装置不参与本局。两种数据分别缓存并保存调配偏好，切回后可恢复对应配置。下文介绍的是**扩展开启时**的内容；六个房间席位与五至六人的多人规则见 [MULTIPLAYER.md](MULTIPLAYER.md)。

六人局在原版与莱茵两种规则下均少 BAN 两个核心盟约，BOSS 共享生命池为对应四人局的 200%，并在第 10、12、14 回合每位存活玩家各发一个信标。第 14 回合奖励信标使用后立即送达；10、12 回合奖励信标沿用下回合送达。

本次同时将五至六人悬赏决策从 6 张增至 9 张：保留原六张，追加现有 I / II / II 阶目标，赏金分别为 1 / 2 / 2；单人与一至四人维持原悬赏张数。

六位新增干员在“干员调配”中选择技能与模组。梅尔、乌啾、星源各 2 个技能，森蚺、伊芙利特、多萝西各 3 个技能；模组种类分别为 1、1、1、2、2、1。默认配置：梅尔 S1“迷惑装置”、SUM-X；乌啾 S2“捉迷藏”、XAH-X；森蚺 S3“钢铁意志”、HES-X；伊芙利特 S2“炎爆”、BLA-X；星源 S1“双端导流”、CHA-Y；多萝西 S3“高速共振排障”、TRP-Y“童话书”。模组只由精锐装备，也可选择不装备。

沿用原项目阶数配置：这六位普通干员技能 Lv.4，精锐技能 Lv.7、模组 Lv.1。数据与效果依据 [梅尔](https://prts.wiki/w/梅尔)、[乌啾](https://prts.wiki/w/乌啾)、[森蚺](https://prts.wiki/w/森蚺)、[伊芙利特](https://prts.wiki/w/伊芙利特) 核对，并使用固定版本客户端数据构建。森蚺特限模组 RA-α 已从可选项移除，旧配置会回退 HES-X。梅尔模组说明为“首个召唤物不占部署位；不过卫戍召唤物本来就不占人口，所以这条效果没了XP”。其他手动选择的有效技能或模组仍然保留，不会被新默认值覆盖。

梅尔普通时提供 1 只机械水獭，精锐时提供 2 只；库存及同时部署上限均随此规则调整，所有技能和模组配置一致。机械水獭不接受干员治疗，包括塞雷娅及赫默医疗无人机等由干员提供的治疗；科研装置“生命维持仪”仍可治疗它。无干员治疗来源的自然回复不受这条限制。

莱茵盟约图标使用 `public/art/rhine/bond.svg`：根据用户提供的莱茵生命标志绘制纯白、透明、无文字的 ∞ / ＋ / － 轮廓，与现有阵营图标的单色风格一致。内置 imagegen 用于生成预览（提示为“保留∞＋－、纯白、透明底、去掉英文”）；预览的透明区域存在杂点，最终游戏资产采用清晰的矢量轮廓。

星源与溯光星源是两位独立干员，莱茵阵容现在共 9 位；本次不添加麦哲伦。梅尔的装置产层、星源的首次技能产层与多萝西的陷阱产层仅在允许战斗叠层的普通主战结算，BOSS 回合、联防、最终攻势和隐秘核心沿用原项目限制。层数立即作用于科研装置，不增加阶段突破研究点，莱茵层数仍最多 999。

梅尔按装置完成一次有效工作计数：能量装置真正发射一次满充脉冲；医疗装置每 3 秒一轮中有生命实际恢复或护盾净增加（两个目标仍只算一次，满血满盾仅刷新持续时间不算）；生态装置累计 3 秒范围内有可选敌人，无敌人时暂停累计。多个目标、持续减速刷新、敌人反复进出和仅展示特效不会额外加层。梅尔不再直接增加装置攻击。

溯光星源每次结算读取本回合累计支出，例如 15 资金给每个已激活目标盟约增加 10 / 20 层。多个副本、森蚺复制及瑰盐售出重触发沿用原版逻辑，各次重新读取完整累计支出；并非把资金仅兑换一次。原版数据档的特质仍只有灵巧、奥术。

多萝西的共振装置库存与同时部署上限为普通 4 枚、精锐 5 枚，所有技能、开场自动放置和预先摆放的陷阱共同遵守此上限。每枚陷阱触发只叠一次层，范围伤害击中多个目标不会重复叠层；三技能连锁中每枚真正引爆的陷阱分别计算，收回或未触发的移除不计。TRP-Y“童话书”保留部署时 20% 概率造成双倍伤害的机制，暴击陷阱显示红色；双倍伤害不增加产层次数。TRP-X“梦中人”不提供。技能和模组依据 [星源](https://prts.wiki/w/Astgenne)、[多萝西](https://prts.wiki/w/多萝西) 核对。

## 开局轮换 BAN

新增干员后的基础轮换：1–4 人开局时，险境、绝境和终极为 4 个核心 + 4 个附加，标准为 1 个核心 + 1 个附加；5–6 人（含 AI）开局时，核心少 BAN 一个，分别为 3 + 4、0 + 1。训练不禁用，难度固定禁用盟约保持原规则。人数在开局时固定，离开或淘汰不会重抽；详见 [多人版说明](MULTIPLAYER.md)。BAN 仍按盟约轮换，只有全部所属盟约被禁用的干员才退出本局卡池；商店各阶概率和同名干员数量不变。核心干员仍受本局 BAN 影响，不保证每一局都能招募某位指定干员。

两件装备均进入对应阶数的商店与通用装备奖励池，普通售价分别为 2、4 资金；两件同名普通装备合成为一件精锐，也支持原有装备升级效果。基础属性对所有携带者有效。多个主机只取当前最强的增益，不叠加；主机持有者离场后重新计算。主机增益计入装置基础攻击，伊芙利特继承及科研成果共享均读取该数值；增益只取科研层数，不读取装置当前攻击力，避免循环。

实验终端本身不赋予莱茵生命盟约。与“变形同构体”同时装备时，携带者才额外获得莱茵生命；普通与精锐终端均支持。主机没有转职效果。

装备图标为本扩展生成的透明 PNG：`public/art/rhine/terminal.png` 与 `public/art/rhine/mainframe.png`，提示和来源见 [生成记录](rhine-equipment-art.json)。

## 科研装置

莱茵人数达到 3 时获得三种装置，各有一个独立科研备牌位，可以部署一台；达到 6 时可以部署两种不同装置；达到 9 时可以同时部署全部三种装置。科研位不占普通备牌格，装置不占干员人数，但占一个可部署格。装置无敌、不被敌人选中、不阻挡，不能出售、装备或赠送。

备战期可以随时更换、撤回和重新摆放。人数掉档时自动收回超出的装置；再次激活保留原来的装置和研究点。

所有装置基础攻击：**300 + 莱茵层数 × 4**，另加己方最强的联合研究主机增益。

医疗装置治疗、能量装置脉冲、伊芙利特继承及科研成果共享均读取这个基础攻击，不读取临时攻击增益；治疗与伤害的结算倍率仍正常生效。

莱茵盟约达到 **6** 时，除伊芙利特及治疗干员（包含塞雷娅）外的己方莱茵输出干员，获得最高单台已部署装置基础攻击力的 **15% / 25%**（普通 / 精锐）作为额外攻击力。多个装置不相加，医疗及生态装置也可提供这份研究成果；层数不被消耗。伊芙利特使用自己的 **100% / 150%** 单台最高值继承，不重复获得共享；退档、装置收回或装备变化时同步更新。转职及调和成员沿用原有成员判定，跨玩家不共享。

| 装置 | 原型 | 第一次突破 | 第二次突破 |
| --- | --- | --- | --- |
| 生命维持仪 | 每 3 秒，治疗半径 2 格内己方生命比例最低的单位，治疗量为装置攻击的 50%。 | 溢出治疗的 50% 转为 6 秒护盾，同源盾累计不超过目标生命上限。 | 每次治疗两个目标。 |
| 能量谐振仪 | 一级：半径 2 格内己方干员发动技能时充能，每 3 次释放 120% 攻击的范围法术脉冲，溅射主目标周围实际半径 1 格。单个干员 3 秒内最多充能一次；无目标时保留满充，进入射程后释放。 | 二级：充能来源扩大至己方全场干员，主目标射程仍为半径 2 格。 | 三级：主目标周围改为塞雷娅“钙质化”相同的 25 格菱形范围；伤害仍为 120%。 |
| 生态调控器 | 一级：半径 2 格内敌人持续减速 50%，不再间歇开启，也不随层数改变减速值。 | 二级：每 8 秒额外束缚范围内敌人 1 秒。 | 三级：区域半径增加 1 格，持续减速保持 50%。 |

层数决定日常数值，参战研究点只决定阶段突破。成功 +2 点、失败 +1 点，每阶段均需要 **5 点**：原型攒满 5 点变为改良型，再重新攒满 5 点变为成熟型。每次突破立即清零，溢出点数不保留（例如 4 点时成功，突破后为 0 点）；成熟型不再积累研究点。阶段单独保存，清零不退级。普通回合以主战无漏怪作为成功，领袖回合按共同胜负结算。只有该回合主战真正部署的装置获得研究点；预览、拖动、重连和联防续战不重复结算。

装置使用三张独立透明贴图：双旋翼医疗探机、线圈谐振塔、生态培养舱。场上有各自的待机和技能触发动态；突破阶段同时反映在装置灯效中。贴图参考原游戏召唤物的机械结构与画面比例，为本扩展新绘制。

选中或预放置装置时，棋盘显示整格作用范围，不再绘制圆圈。基础半径 2 格时包含中心在欧氏距离 2 格内的 13 格；生态突破Ⅱ为半径 3 格的 29 格，不随朝向变化。边缘越界格不显示，范围适配高台及镜像阵地。实际充能、治疗、选敌与生态作用使用同一格子判定；移动单位按当前所在格判定，巨型敌人任一占据格进入范围即可受影响。能量一级、二级溅射按主目标周围欧氏距离 1 格计算；三级按主目标所在格为中心的钙质化 25 格菱形计算（曼哈顿距离不超过 3，不包含偏移 2 / 2 的四个角格），与半径 3 的 29 格圆形有区别。二级起己方全场开技能均能充能，范围预览仍显示装置选主目标的 13 格射程。

能量谐振仪下方显示技能条样式的充能进度，依次为 0 / 3、1 / 3、2 / 3，满 3 点且有目标时攻击后回到 0；无目标时保持 3 / 3，敌人进入射程后发射；重连或观战同步当前进度。每次发射都有装置闪光、指向目标的光束和命中效果，低画质也保留明确反馈。科研备牌卡与详情面板同步说明当前范围。尚无战斗实时属性时，详情的 300 攻击明确标为“基础攻击”，未计科研层数、装备或梅尔增益。

可复现的界面验收地址为 `/dev/game-mock.html?phase=PREP&variant=rhineRange&researchDevice=ecology&researchStage=2`；该开发场景提供成熟生态装置及四件普通／精锐科研装备，仅用于界面检查。

- 资源补全：`node tools/fetch-rhine-assets.mjs`。干员头像、立绘、技能图标及 Spine 使用原项目同源资源；三个装置使用本扩展通过 imagegen 新绘制的透明 PNG 与程序动画，盟约及后备图标为 SVG。机械水獭使用上游提供的同角色 `ghost_1` 模型。

首次从源码运行：
```powershell
npm ci
npm run setup
npm start
```

`setup` 调用已包含莱茵资源计划的通用下载器。已有原版资源时可单独运行 `node tools/fetch-rhine-assets.mjs` 补全扩展资源。扩展数据已经提交，无需为了正常游玩重新构建；修改扩展数据后运行 `node tools/rhine-data.mjs`，再执行 `npm test`。

默认浏览器地址为 `http://127.0.0.1:3000/`。需要使用启动器并指定监听范围时，可在项目目录执行：

```powershell
node scripts/launch.mjs --port 3000 --host 127.0.0.1 --no-setup
```

仅本机游玩或使用本机隧道时可监听 `127.0.0.1`；需局域网直连时改为 `--host 0.0.0.0`，并按 [DEPLOY.md](DEPLOY.md) 配置防火墙。穿透或反向代理应转发选定端口及 `/ws` WebSocket，不要把私人隧道地址或认证令牌提交到仓库。

更新前备份当前版本，在现有对局全部结束后停止旧服务，再安装新版依赖、检查资源并启动。启动器不会自动替换已占用同一端口的服务。客户端和服务端须使用同一份代码与数据，更新后刷新网页再开新房间。回退时停止新版并从备份目录启动；对局保存在进程内存中，重启或回退都不能恢复已结束的旧进程对局。
