# 莱茵生命 · 联合科研（非官方扩展）

当前正式版本：`v0.2.1-rhine.1`；正式源码分支：`codex/rhine-upstream-021`。本分支为 `codex/rhine-device-rework`，包含 2026-10-08 装置重做实验，尚未发布到正式包或线上服务。

本扩展基于 [sganggs/Stronghold-Protocol](https://github.com/sganggs/Stronghold-Protocol) v0.2.1（官方发布提交 `c2a2ef7`），保留原玩法及该版本修复，并加入莱茵生命研究路线。修改日期为 2026-10-07。它是独立同人扩展，不是上游官方更新；修改范围见 [RHINE-CHANGES.md](RHINE-CHANGES.md)。

## 房间扩展开关

独立模拟与同盟模拟的新房间默认开启“莱茵生命扩展”。房主可在等待室选择“开启”或“原版”，所有玩家都能看到设置；只能在开始模拟前更改。切换会取消队友准备状态，并在对应数据加载、干员调配同步完成后恢复开局操作。各房间独立设置，对局开始及断线重连后继续使用本局固定选择。

“原版”使用随包固定的上游 v0.2.1 原版数据，恢复原版的干员、阶数、盟约、特质、装备和机变内容，扩展干员与科研装置不参与本局。两种数据分别缓存并保存调配偏好，切回后可恢复对应配置。下文介绍的是**扩展开启时**的内容；六个房间席位与五至六人的多人规则见 [MULTIPLAYER.md](MULTIPLAYER.md)。

六人局在原版与莱茵两种规则下均少 BAN 两个核心盟约，BOSS 共享生命池为对应四人局的 200%，并在第 10、12、14 回合每位存活玩家各发一个信标。第 14 回合奖励信标使用后立即送达；10、12 回合奖励信标沿用下回合送达。

本次同时将五至六人悬赏决策从 6 张增至 9 张：保留原六张，追加现有 I / II / II 阶目标，赏金分别为 1 / 2 / 2；单人与一至四人维持原悬赏张数。

沿用原项目阶数配置：这六位普通干员技能 Lv.4，精锐技能 Lv.7、模组 Lv.1。数据与效果依据 [梅尔](https://prts.wiki/w/梅尔)、[乌啾](https://prts.wiki/w/乌啾)、[森蚺](https://prts.wiki/w/森蚺)、[伊芙利特](https://prts.wiki/w/伊芙利特) 核对，并使用固定版本客户端数据构建。森蚺特限模组 RA-α 已从可选项移除，旧配置会回退 HES-X。梅尔模组说明为“首个召唤物不占部署位；不过卫戍召唤物本来就不占人口，所以这条效果没了XP”。其他手动选择的有效技能或模组仍然保留，不会被新默认值覆盖。

梅尔普通时提供 1 只机械水獭，精锐时提供 2 只；库存及同时部署上限均随此规则调整，所有技能和模组配置一致。机械水獭不接受干员治疗，包括塞雷娅及赫默医疗无人机等由干员提供的治疗；科研装置“生态维持仪”仍可治疗它。无干员治疗来源的自然回复不受这条限制。

莱茵盟约图标使用 `public/art/rhine/bond.svg`：根据用户提供的莱茵生命标志绘制纯白、透明、无文字的 ∞ / ＋ / － 轮廓，与现有阵营图标的单色风格一致。内置 imagegen 用于生成预览（提示为“保留∞＋－、纯白、透明底、去掉英文”）；预览的透明区域存在杂点，最终游戏资产采用清晰的矢量轮廓。

星源与溯光星源是两位独立干员，莱茵阵容现在共 9 位；本次不添加麦哲伦。梅尔的装置产层、星源的首次技能产层与多萝西的陷阱产层仅在允许战斗叠层的普通主战结算，BOSS 回合、联防、最终攻势和隐秘核心沿用原项目限制。层数立即作用于科研装置，不增加阶段突破研究点，莱茵层数仍最多 999。

梅尔按装置完成一次有效工作计数：能量装置每次真正发射脉冲算一次；生态维持仪将实际回血、净增盾与每累计3秒有效减速合并计数，同台3秒内最多一次；激光钻机每累计3秒有效输出算一次。多个目标或伤害帧不重复产层，封顶护盾仅刷新时长不算。梅尔不直接增加装置攻击。

溯光星源每次结算读取本回合累计支出，例如 15 资金给每个已激活目标盟约增加 10 / 20 层。多个副本、森蚺复制及瑰盐售出重触发沿用原版逻辑，各次重新读取完整累计支出；并非把资金仅兑换一次。原版数据档的特质仍只有灵巧、奥术。

多萝西的共振装置库存与同时部署上限为普通 4 枚、精锐 5 枚，所有技能、开场自动放置和预先摆放的陷阱共同遵守此上限。每枚陷阱触发只叠一次层，范围伤害击中多个目标不会重复叠层；三技能连锁中每枚真正引爆的陷阱分别计算，收回或未触发的移除不计。TRP-Y“童话书”保留部署时 20% 概率造成双倍伤害的机制，暴击陷阱显示红色；双倍伤害不增加产层次数。TRP-X“梦中人”不提供。技能和模组依据 [星源](https://prts.wiki/w/Astgenne)、[多萝西](https://prts.wiki/w/多萝西) 核对。

## 开局轮换 BAN

新增干员后的基础轮换：1–4 人开局时，险境、绝境和终极为 4 个核心 + 4 个附加，标准为 1 个核心 + 1 个附加；5–6 人（含 AI）开局时，核心少 BAN 一个，分别为 3 + 4、0 + 1。训练不禁用，难度固定禁用盟约保持原规则。人数在开局时固定，离开或淘汰不会重抽；详见 [多人版说明](MULTIPLAYER.md)。BAN 仍按盟约轮换，只有全部所属盟约被禁用的干员才退出本局卡池；商店各阶概率和同名干员数量不变。核心干员仍受本局 BAN 影响，不保证每一局都能招募某位指定干员。

## 科研装置

3莱茵获得生态维持仪与能量谐振仪，可以部署一台；6莱茵可以部署两种不同装置；9莱茵解锁只有一级的激光钻机，允许同时部署三种。三种各有一个固定科研备牌位，未解锁的钻机位显示9人门槛。装置不占干员人数或普通备牌格，占一个可部署格；无敌、不被选中、不阻挡，不能出售、装备或赠送。

备战可自由摆放与收回。少于9莱茵时先收回钻机，再按容量收回其他装置。恢复人数保留装置UID与研究成果。旧的独立生态调控器已合并进生态维持仪。

所有装置基础攻击A＝300＋莱茵层数×4＋己方最强联合研究主机加成。治疗、脉冲、激光法术伤害、伊芙利特继承与成果共享都读取A，不读取临时攻击增益；治疗与伤害的最终倍率正常结算。

6莱茵时，除伊芙利特和治疗干员（包含塞雷娅）外的己方莱茵输出干员，共享最高单台已部署装置基础攻击的15%／25%（普通／精锐）。多个装置不相加，跨玩家不共享。伊芙利特只取自己的100%／150%继承，不重复共享。

| 装置 | 一级 | 二级 | 三级 |
| --- | --- | --- | --- |
| 生态维持仪 | 半径2格内持续减速50%；每3秒治疗1名生命比例最低的友军，恢复75%A。 | 每次治疗2人；范围内己方干员接受任意来源治疗时，获得最终治疗量25%＋溢出治疗50%的护盾，持续6秒，同源累计上限为目标最大生命值40%。 | 半径3格；每次治疗3人，各恢复100%A；每8秒束缚范围内敌人1秒，保留全来源治疗护盾。 |
| 能量谐振仪 | 半径2格内己方干员开技能充能，3点充能对装置范围内全部敌人造成180%A法术伤害。 | 己方全场技能充能；选敌半径3格，伤害240%A，主目标周围半径1格溅射。 | 伤害300%A，以主目标所在格为中心，钙质化25格菱形溅射。 |
| 激光钻机 | 仅9莱茵可用，全场选择面板最大生命值最高的敌人，锁定至死亡或永久离场。初始每秒150%A法术伤害，有效输出每秒增加初始伤害5%，20秒封顶300%A；随后每秒追加目标最大生命值0.5%的真实伤害，领袖按本战场分摊最大生命值计算。 | 无突破。 | 无突破。 |

生态护盾读取治疗加成、受疗加成与治疗钩子结算后的最终治疗量。禁疗、零治疗和自然生命回复不触发盾。满血单位接受有效治疗时可生成溢出盾。护盾归受疗干员所在玩家的装置，治疗来源可以是本方或队友的干员、技能或其他装置；范围护盾仅作用于干员。装置自身仍可治疗机械水獭。生命比例相同时优先治疗自身装置护盾较少的目标。

能量装置同一干员3秒内最多贡献一次，脉冲最短发射间隔1.5秒；无目标或间隔未到时保留满充能。一级直接命中装置整格范围内全部敌人；二、三级仍以一个主目标为中心溅射。

钻机选敌使用最大生命值，目标死亡或永久离场才重选并清空增伤；后来出现更高生命的敌人不会抢走火力。目标暂时隐匿、无敌或不可选中时暂停输出及计时，恢复后继续。伤害不受普攻攻速影响。真实伤害在满20秒后按每秒结算，首次在有效输出21秒时产生。领袖基数固定为本轮共享总生命值÷本轮战场数；六人三个战场时为总生命值的1/3，其他战场结束不改变这个基数，同场镜像领袖不重复打一台钻机的一次伤害。

生态与能量沿用胜利＋2／失败＋1研究点，每次突破需要5点，突破后清零并丢弃溢出，成熟型不再积点；阶段独立保存。只结算真实主战参与，预览、重连、摆放及联防续战不重复结算。钻机只有一级，阶段与研究点恒0。

梅尔：能量脉冲每次发射算一次工作；生态仪的实际回血、净增盾和每累计3秒有效减速合并计数，同台3秒内最多一次；钻机每累计3秒有效输出算一次，不按激光伤害帧产层。普通主战之外不增加盟约层数。

范围按完整格判定：半径2格为13格，半径3格为29格，朝向不影响。一级能量命中自己的13格；三级能量溅射用钙质化25格菱形。钻机显示全场范围，并显示锁定目标、0～20秒增伤进度和达到上限后的颜色反馈；观看、重连和低画质保留这些反馈。

界面验收：`/dev/game-mock.html?phase=PREP&variant=rhineRange&researchDevice=medical&researchStage=2`；将 `researchDevice` 改为 `laser` 可查看九莱茵钻机的单级卡片与全场范围。`variant=rhineLaser` 提供三装置的画面示范；模拟页面用于检查画面，战斗强度以真实模拟器测试及实际对局为准。

- 六位干员战斗入口：`server/sim/content/kits/rhine.js`，具体技能分别在 `rhineSupport.js`、`rhineAssault.js` 与新增研究干员技能文件。
- 装置、梅尔、塞雷娅和伊芙利特科研效果：`server/sim/content/rhine.js`。
- 白面鸮叠层：`server/sim/content/rhineMeta.js`。
- 部署限制、研究点：`server/match/player/research.js`，普通与领袖结算分别在 `server/match/match/combat.js`、`bossRounds.js`。
- 资源补全：`node tools/fetch-rhine-assets.mjs`。干员头像、立绘、技能图标及 Spine 使用原项目同源资源；生态维持仪与能量谐振仪使用本扩展生成的透明 PNG 与程序动画，新增激光钻机使用本地 `public/art/rhine/laser.svg` 与持续光束、增伤反馈动画。盟约及后备图标为 SVG。机械水獭使用上游提供的同角色 `ghost_1` 模型。

首次从源码运行：
```powershell
npm ci
npm run setup
npm start
```

`setup` 调用已包含莱茵资源计划的通用下载器。已有原版资源时可单独运行 `node tools/fetch-rhine-assets.mjs` 补全扩展资源。扩展数据已经提交，无需为了正常游玩重新构建；修改扩展数据后运行 `node tools/rhine-data.mjs`，再执行 `npm test`。

默认浏览器地址为 `http://127.0.0.1:3000/`。需要使用启动器并指定监听范围时，可在项目目录执行：

```powershell
node scripts/launch.mjs --port 3000 --host 127.0.0.1 --no-setup
```

仅本机游玩或使用本机隧道时可监听 `127.0.0.1`；需局域网直连时改为 `--host 0.0.0.0`，并按 [DEPLOY.md](DEPLOY.md) 配置防火墙。穿透或反向代理应转发选定端口及 `/ws` WebSocket，不要把私人隧道地址或认证令牌提交到仓库。

更新前备份当前版本，在现有对局全部结束后停止旧服务，再安装新版依赖、检查资源并启动。启动器不会自动替换已占用同一端口的服务。客户端和服务端须使用同一份代码与数据，更新后刷新网页再开新房间。回退时停止新版并从备份目录启动；对局保存在进程内存中，重启或回退都不能恢复已结束的旧进程对局。
